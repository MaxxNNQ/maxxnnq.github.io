Политика конфиденциальности

Дата: 9 октября 2026 г.

vault-drive — личное приложение. Оно получает доступ к Google Диску и Google Таблицам только того аккаунта, владелец которого сам дал разрешение, и только для синхронизации его файлов и работы с его таблицами.

  • Данные Google (файлы, таблицы) читаются и записываются только по командам владельца.
  • Данные не передаются третьим лицам, не продаются и не используются для рекламы.
  • Ключи доступа хранятся на личном компьютере владельца с ограниченными правами доступа.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy Policy (English)

vault-drive is a personal app. It accesses only the Google Drive and Google Sheets of the account owner who granted permission, solely to sync the owner's files and work with the owner's spreadsheets. Data is not shared with third parties, sold, or used for advertising. Credentials are stored on the owner's own machine. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
