vault-drive

vault-drive — личное приложение для синхронизации рабочей папки владельца с его собственным Google Диском и для работы с его собственными Google Таблицами. Приложение используется только владельцем аккаунта и не предназначено для других пользователей.

vault-drive is a personal application that syncs the owner's working folder with the owner's own Google Drive and works with the owner's own Google Sheets. It is used only by the account owner.
